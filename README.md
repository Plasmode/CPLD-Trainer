# CPLD-Trainer
CPLD Trainer explores the world of complex programmable logic device (CPLD) and how it interacts with 6502, Z80, and other processor and memories.
Discussion about CPLD-Trainer can be found here: http://forum.6502.org/viewtopic.php?f=10&t=6974
Rev0 of CPLD-Trainer worked with 6502 CPU only.  Rev1 of CPLD-Trainer works with 6502, Z80, and another unspecified processor in 40-pin DIP package.  This page describes the Rev1 CPLD-Trainer; Rev0 of CPLD-Trainer can be found here:
<img width="5224" height="5160" alt="cpldtrainerforz806502andgenericcpu" src="https://github.com/user-attachments/assets/4d357b05-902d-4af7-ba7d-4312c9b89872" />

Because Rev1 CPLD Trainer can work with Z80, 6502, and an unspecified 40-pin 8-bit processor, there are multiple configurations of Rev1 CPLD Trainer.  Currently there are two sub-folders describing the Z80 configuration, https://github.com/Plasmode/CPLD-Trainer/tree/main/Rev1Z80-trainer and 6502 configuration https://github.com/Plasmode/CPLD-Trainer/tree/main/Rev1_6502_CPLD_trainer.
