Rev1 CPLD trainer configured to 6502 CPU
6502 implementation requires 7.37MHz oscillator, W65C02, 512K RAM (e.g. AS6C4008), and 512K flash (e.g. SST39SF040)
<img width="1188" height="1545" alt="Rev1_CPLD_trainerwith6502" src="https://github.com/user-attachments/assets/ee86bfd8-40b0-491e-880a-5c3f9e4e0cbb" />
There are 10 training sessions described in 6502.org between Jan 27 and Feb 6, 2022.  Each of the training session is saved in dedicated sub-folders.
There are also dedicated sub-folder for project using 6502 CPLD trainer
